# 高速数据采集卡代码

基于zlinear FPAG高速数据采集卡代码进一步编写，数据采集卡本体为STM32H7+FPGA组合，上位机原始基于C#语言进行编写，本仓库的目标是基于zlinear公司qt上位机代码进一步编写一个适合本硬件的上位机代码

## 设备与环境信息

1. 设备型号：zlinear USB高速数据采集卡 DABM-D223B(500K)
2. 嵌入式设备开发环境：keil+vscode
3. 上位机开发环境：C# **/** Qt
